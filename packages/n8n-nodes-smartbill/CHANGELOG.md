### Added

- SmartBill node. Invoice: Create, Get PDF, Get Payment Status, Cancel, Restore, Delete, Reverse and
  Send by Email (API V1). Client: Get and Get Many (API V3).
- SmartBill API credential with Basic auth for V1, an optional Bearer token for V3, and a test request.
